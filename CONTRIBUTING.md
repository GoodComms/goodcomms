# Contributing to GoodComms

GoodComms is **closed-source, proprietary software**. We do not accept code contributions or pull requests.

---

## How You Can Help

### Bug Reports
A well-written bug report is the most valuable thing you can do.

1. Search [existing issues](https://github.com/goodcomms/goodcomms/issues) first — it may already be reported.
2. Use the **Bug Report** template when opening a new issue.
3. Include your OS, version, steps to reproduce, and console logs (Settings → Console → Log to File).

### Feature Requests
Open a Feature Request issue describing the problem you want solved. Be specific about the use case. We read all of them.

### Security Vulnerabilities
Do **not** open a public issue. See [SECURITY.md](SECURITY.md).

---

## Support

For general questions or support, open a [GitHub Discussion](https://github.com/goodcomms/goodcomms/discussions) or reach out at **contact@goodcomms.app**.
